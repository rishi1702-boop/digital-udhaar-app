# Digital Udhaar Khata

Digital Udhaar Khata is a modern web application designed for small business owners and shopkeepers to manage their daily ledgers, customer credit (Udhaar), and cash flow. It digitizes the traditional notebook system, providing automated tracking, PDF statements, and direct payment reminders.

## Project Structure

The project is divided into two main folders, each with its own detailed documentation:

1. **[Frontend Documentation](./frontend/README.md)**
   Built with React.js and Vite. This folder contains the Single Page Application (SPA) and all user interface components.

2. **[Backend Documentation](./backend/README.md)**
   Built with Node.js, Express, and MongoDB. This folder contains the REST API, database models, and external integrations.
